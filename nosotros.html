Proyecto académico

Café peruano, historias que se comparten.

SAYRI PERU propone una experiencia digital sobre café, recetas sencillas y momentos de conexión cotidiana.

Nuestra idea

Una identidad creada para este proyecto

Construimos una marca conceptual que pone en valor la conversación, el aprendizaje y el consumo responsable. El contenido de esta web fue redactado para el proyecto y puede adaptarse a la propuesta real del equipo.

“Una taza puede ser una pausa, una conversación o el inicio de una idea.”

01

Origen

Reconocemos el trabajo que existe detrás de cada grano y promovemos información clara para quien visita el sitio.

02

Comunidad

Invitamos a compartir preparaciones, preferencias y recomendaciones mediante el formulario de contacto.

03

Creatividad

Transformamos recetas cotidianas en propuestas visuales simples, accesibles y fáciles de explorar.

Proceso del equipo

Del concepto a la interfaz

  1. Investigar: definir público, objetivos y estructura de información.
  2. Diseñar: crear una paleta cálida, jerarquía visual y páginas responsivas.
  3. Desarrollar: implementar HTML, CSS y JavaScript para navegación y formularios.
  4. Probar: verificar la web en escritorio y móvil antes de la presentación.
